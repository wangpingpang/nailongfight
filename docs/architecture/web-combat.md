# 电脑网页运行时

基线 `c239f3a` 安装了 Game Studios 1.3.0 模板。原有 `src` 仅含协作说明与目录占位。T01 选用浏览器原生 ES 模块、Canvas 2D 和 DOM。制作、运行和逻辑测试使用 Node.js 20+ 自带组件，玩家离线打开单文件构建即可进入大厅。

| 文件 | 职责 |
|---|---|
| `src/game/data/game.json`、`config.mjs` | 校验角色、技能、场地、AI、关卡、资源、资产与键位引用。数值均为假设值。每次开局重新载入，单局持有独立配置快照。 |
| `controls.mjs` | 两位玩家独立按键边沿与按住状态。游戏时钟按配置固定步长推进，窗口失焦暂停并清空输入。 |
| `combat.mjs` | 统一状态机、同帧命中快照、招架、脱身、连击保护、奥义、死亡与终局。 |
| `stages.mjs` | 电脑从已发生的场上状态生成动作，与键盘共用输入接口。管理三关、入场预警、波次转换。 |
| `progress.mjs` | 在同源互斥锁内重读并保存完整账户，存下首通、解锁、升级和场次凭据。备份与提示处理异常存档。 |
| `art.mjs`、`assets/`、`ui.mjs` | 原创场景和角色、攻击预警、命中反馈、各页面与可重绑输入。美术资源独立于碰撞形状。 |
| `main.mjs` | 连接页面、键盘、对局、场次结算与暂停。只有闯关使用成长属性和发放奖励。 |

## 配置与试玩

调整招式时编辑 `data/game.json` 的 `skills` 表，例如 `shell.s1.cd` 从 480 改成 600 后，新对局中冲撞冷却由 8 秒变为 10 秒。修改数值之后运行 `npm test`。离线版需要重新运行 `npm run build`。浏览器中的存档按访问来源隔离，离线文件和本地开发网址各自保存。首通第一关奖励 50 点，解锁慢团团和第二关，第一次升级消耗 50 点。

## 模式边界

人机、同机双人和训练共用竞技级别基线。双人仅支持两人共用本机键盘。不同键盘的同时按键能力可能不同，可在设置中重绑冲突组合。远程联机涉及网络同步、断线和暂停约定，待双人形式确认后另行处理。公网内测属于 T09。

## 资产与内容

参考的是结构，不是表达（B4）。角色标识、显示名、程序效果与本地矢量素材均可替换，逐项来源及真人、原 IP 表达检查在 `assets` 配置表。五位角色的动作音效使用本地原创合成的 MP3，通用命中声使用实时振荡器与噪声。角色与素材的对应关系、音量、脚步间隔与蓄势阈值可在 `game.json` 的 `fighterAudio` 调整。名称与素材的对外发布复核仍待进行（C5、C6、J3）。
