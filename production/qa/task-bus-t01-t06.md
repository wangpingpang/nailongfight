## 变更记录与验收入口

- 从原有工作室模板新增首个可运行版本。人机镜像对手复用公共动作接口，配合单人优先的开发顺序完成选角、对局、结算与重赛入口。
- `npm test` 执行数据、输入时钟、战斗、AI、关卡和经济测试。`tests/game/campaign.test.mjs` 从新存档开始，依次通关三关、首通升级、载入已保存进度并检查重复结算。
- `npm run build` 校验游戏配置和本地资源，生成离线文件。浏览器冒烟脚本为 `scripts/browser-smoke.py`，覆盖正常页面流、暂停、重赛、本机双人和离线入口，截图目标目录为 `production/qa/evidence/`。
- 本轮检查项目素材来源、自绘非人形角色与合成音效，资产表保留逐项复核记录。公开名称、商标与对外发布仍需另行核验（C5、C6）。
- 待验收项包括目标电脑连续十分钟的帧率、实体键盘多键同时按下的表现及双人玩法定案。公网部署与跨网访问验收归 T09。
